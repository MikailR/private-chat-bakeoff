Privacy

What stays on this device

Kiln answers in this browser tab. The model is LaMini-Flan-T5-77M, an open 77-million-parameter network, running through WebAssembly on this device. The weights ship with the app. The reply is computed here.

Your chats are written to IndexedDB in this browser profile. Reloading the page keeps them. They are not sent to a server, and there is no account.

While it is open, this page loads only its own files — the script, the fonts, the WebAssembly runtime, and the model weights — from the same address that served the page. It does not call a hosted chat API. There is no analytics beacon.

Left out on purpose: accounts, cloud sync, plugins, voice, images, and a catalog of models.
