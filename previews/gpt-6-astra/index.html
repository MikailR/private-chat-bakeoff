PRIVATE BY DESIGN

Here means here.

Your conversation belongs on your device. Here’s exactly what that means in this prototype.

Replies happen locally

Offline tools run in this browser. The optional language model runs in Ollama on this same computer. No hosted chat API.

History stays in this browser

Messages, titles, and your engine choice are saved in local storage. No accounts, analytics, or sync. App files are cached for offline reloads.

Private doesn’t mean encrypted

History is plain text in your browser profile. Someone with access to that profile can read it. Clearing browser data removes your chats; private browsing may not retain them.

Ollama LOCAL MODEL

A fuller conversation with Llama 3.2 1B, running on your computer.

After installing Ollama, run:

OLLAMA_NO_CLOUD=1 ollama serve
ollama pull llama3.2:1b

Run these in separate terminals. Downloading weights needs internet once. Start the Ollama server with cloud features disabled.

Only 127.0.0.1:11434. No custom endpoints.

On mobile or a static site, use offline tools. The Ollama bridge requires this app’s local Node server on the same device.
